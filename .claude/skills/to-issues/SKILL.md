# To Issues

Break work into tracer-bullet vertical slices, not horizontal layers.

Each issue must deliver a narrow but complete path through all relevant layers and be independently demoable or verifiable.

For each slice show:

- Title
- Type: AFK or HITL
- Blocked by
- User stories covered
- Acceptance criteria

Prefer many thin slices over few thick ones. Publish blockers first. Do not close or modify parent issues.
