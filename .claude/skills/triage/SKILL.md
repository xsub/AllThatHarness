# Triage

Every posted comment or issue generated during triage must start with:

```markdown
> *This was generated by AI during triage.*
```

Roles:

- category: `bug` or `enhancement`
- state: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`

Each triaged issue carries exactly one category and one state role. If states conflict, stop and ask maintainer.

## Specific issue flow

1. Gather full issue context: body, comments, labels, reporter, dates, prior triage notes.
2. Read domain glossary, ADRs, and out-of-scope knowledge.
3. Recommend category and state with reasoning.
4. For bugs, attempt reproduction before grilling.
5. Grill only when needed.
6. Apply outcome:
   - ready-for-agent: post durable agent brief
   - ready-for-human: explain why not delegable
   - needs-info: specific questions only
   - wontfix: explain and close; record rejected enhancement if useful
   - needs-triage: apply role

Do not re-ask resolved questions when resuming prior triage.
